# Examen Práctico — Análisis de Sensores Industriales

## Objetivo del Proyecto
Este proyecto analiza un conjunto de datos con **100,000 mediciones simuladas** de temperatura y vibración de sensores instalados en cuatro plantas industriales. El objetivo es identificar anomalías térmicas (alertas > 85 °C) y evaluar el comportamiento operativo de los equipos.

> **Nota:** Todos los datos contenidos en `data/sensores_industriales.csv` son simulados para fines didácticos.
